# Evaluation harness

Reproduces the results table in the project [README](../README.md#results).

No media is stored in this repository. `manifest.json` records the Commons
download URL for each clip, and `corpus.py` fetches the media, extracts the audio,
and writes the reference subtitles into a cache **outside** the working tree —
`~/.cache/sub-tools/evals` by default, overridable with `SUB_TOOLS_EVAL_CACHE`.
A clean checkout is text-only; run `corpus.py` to rebuild the corpus.

## Corpus

Five public-domain clips (23.3 min), each with a human-authored English subtitle
track published alongside the media on Commons. Source URLs are in
`manifest.json`.

| clip | source | length | reference cues |
|---|---|---:|---:|
| `obama-2009-06-13` | White House weekly address | 289s | 89 |
| `obama-2009-09-12` | White House weekly address | 261s | 85 |
| `obama-2009-11-28` | White House weekly address | 243s | 78 |
| `nasa-hubble-36th` | NASA narration | 299s | 86 |
| `nasa-orion-10-days` | NASA multi-speaker interview | 306s | 85 |

Two references needed documented fixes, both applied in `corpus.py`: speaker
labels (`The President:`) are stripped, since no variant is asked to do
diarization, and one track's stray blank line between a timestamp and its text is
rejoined so the file parses at all.

A sixth clip (`2009-04-11`) was fetched first and dropped. Its subtitle track is
offset ~3.3s against the media: every transcript agreed with the others to within
0.1s and disagreed with the reference by the same 3.3s, which tripled SubER for
all five variants and buried the differences under a shared timing penalty.
`verify_sync.py` encodes that check so it fails loudly rather than silently
skewing a future run.

## Pipeline

```shell
uv run python evals/corpus.py   # downloads to the cache, prints its location

# "without sub-tools": model gets the audio, returns a subtitle file
uv run python evals/run_gemini_direct.py --model gemini-3.7-flash \
  --variant gemini-3.7-flash-direct --api-key "$GEMINI_API_KEY"

# "with sub-tools": WhisperX transcribes once, the model proofreads it
uv run sub-tools --tasks transcribe \
  --audio-file ~/.cache/sub-tools/evals/audio/CLIP.mp3 \
  --srt-file CLIP.srt --output evals/output/whisperx --languages en
uv run python evals/run_subtools.py --model gemini-3.7-flash \
  --variant gemini-3.7-flash-subtools

uv run python evals/normalize.py
uv run python evals/verify_sync.py
uv run python evals/score.py
```

Every script except `corpus.py` resolves the corpus through `paths.py` and exits
with a clear message if the cache is empty, so a missing download never turns
into a silently partial score.

Both Gemini configurations use the generation settings from
`sub_tools.intelligence.gemini` (thinking level HIGH, Google Search enabled), so
the only thing that varies between them is the pipeline.

`normalize.py` writes `scored/` from `output/`, applying syntax-only repairs —
Markdown code fences, timestamps missing the hours field, missing blank lines
between cues — to every variant identically. Well-formed files pass through
byte-identical, and it records which files needed repair. This exists because an
unparseable file would otherwise be dropped from scoring entirely, which would
quietly reward a model for emitting garbage.

`score.py` runs the shipped `sub-tools-eval` command once per clip and
macro-averages the per-clip metrics.

Run artifacts — `output/`, `scored/`, `reports/`, `results.json`, `results.md`,
`normalization.json` — are gitignored. They are regenerated by a run, and the
summary worth keeping is published in the project
[README](../README.md#results).

## Notes

- WhisperX runs on CPU (`int8`, `large-v2`) at roughly 0.5x realtime here; the
  Gemini calls dominate nothing except when the API is under load.
- `gemini-3.7-flash` returned intermittent `503 UNAVAILABLE` during these runs.
  Both runners retry with backoff, and `run_subtools.py` retries the whole
  `sub-tools` invocation because the pipeline itself only retries
  `ResourceExhausted`, not `ServerError`.
- `run_gemini_direct.py` also retries a response that contains no cues at all: a
  request occasionally comes back as a stray tool-call rendering rather than a
  subtitle file.
